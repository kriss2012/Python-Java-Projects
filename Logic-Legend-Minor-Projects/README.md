## 🚀 Quick Launch Directory

### 🐍 Python Applications (10 Projects)
1. [**PY-01: Smart Expense Tracker with Analytics**](Python-Projects/PY-01-Smart-Expense-Tracker) — Desktop personal finance manager with budget alerts, SQLite persistence, and Matplotlib analytics.
2. [**PY-02: AI Chatbot for College Queries**](Python-Projects/PY-02-College-Chatbot) — Flask web conversational agent with TF-IDF intent classification and administrative Q&A management.
3. [**PY-03: Face Recognition Attendance System**](Python-Projects/PY-03-Face-Attendance) — Biometric webcam attendance tracker with duplicate suppression, student registration, and CSV reporting.
4. [**PY-04: Fake News and Spam Message Detector**](Python-Projects/PY-04-Fake-News-Spam-Detector) — Web NLP classifier comparing Naive Bayes, Logistic Regression, and SVM with confusion matrices.
5. [**PY-05: Weather Dashboard and Forecast App**](Python-Projects/PY-05-Weather-Dashboard) — Streamlit interactive weather application with 5-day forecasts, Plotly charts, and offline demo mode.
6. [**PY-06: Personal Voice Assistant**](Python-Projects/PY-06-Voice-Assistant) — Desktop voice interface for web searches, system automation, to-dos, and security allowlists.
7. [**PY-07: Student Performance Predictor**](Python-Projects/PY-07-Student-Performance-Predictor) — Streamlit machine learning dashboard with regression/classification models and at-risk student intervention alerts.
8. [**PY-08: Price Tracker with Web Scraping**](Python-Projects/PY-08-Price-Tracker) — Autonomous price monitor with BeautifulSoup scraping, SQLite price history, and SMTP email alerts.
9. [**PY-09: Secure Password Manager**](Python-Projects/PY-09-Password-Manager) — AES-256 encrypted credential vault with PBKDF2 key derivation, password generator, and auto-lock.
10. [**PY-10: Sentiment Analysis of Product Reviews**](Python-Projects/PY-10-Sentiment-Analysis) — Streamlit customer review analyzer with VADER scoring, word clouds, and aspect-based sentiment breakdowns.

### ☕ Java Applications (10 Projects)
1. [**JV-01: Online Banking and ATM Simulation**](Java-Projects/JV-01-Banking-ATM-Simulation) — Java Swing banking simulation with transactional fund transfers, PIN lockout, and mini-statements.
2. [**JV-02: Hospital Management System**](Java-Projects/JV-02-Hospital-Management) — Desktop medical management app with patient records, doctor scheduling, and appointment conflict prevention.
3. [**JV-03: Library Management System**](Java-Projects/JV-03-Library-Management) — Library catalog, book issue/return tracking, automatic fine calculation, and inventory reports.
4. [**JV-04: Online Quiz and Examination Portal**](Java-Projects/JV-04-Quiz-Examination-Portal) — Web-based timed quiz platform with randomized questions, server-enforced timeouts, and instant scoreboards.
5. [**JV-05: Multi-User Chat Application**](Java-Projects/JV-05-Multi-User-Chat) — Multithreaded TCP socket client-server chat application supporting group rooms, private whispers, and online tracking.
6. [**JV-06: Inventory and Billing System**](Java-Projects/JV-06-Inventory-Billing) — Point-of-Sale desktop system with barcode/SKU billing, transactional stock deduction, GST, and printable invoices.
7. [**JV-07: Student Management Portal (Spring Boot)**](Java-Projects/JV-07-Student-Management-Portal) — Enterprise Spring Boot application with Spring Data JPA, Thymeleaf, Spring Security, and Swagger OpenAPI docs.
8. [**JV-08: Movie or Event Ticket Booking System**](Java-Projects/JV-08-Ticket-Booking) — Spring Boot web booking portal with interactive seat grids, transactional double-booking guards, and hold timeouts.
9. [**JV-09: Employee Payroll System**](Java-Projects/JV-09-Employee-Payroll) — Desktop payroll software with configurable salary allowances, deductions, tax slabs, and PDF payslips.
10. [**JV-10: Android Expense and To-Do Manager**](Java-Projects/JV-10-Android-Expense-Todo) — Native Android application with Room Database ORM, MPAndroidChart analytics, offline-first storage, and dark mode.

## 🏆 Project Deliverables Standards

Every project in this suite strictly contains:
- **Production Source Code**: Cleanly organized into models, services, repositories, and interfaces.
- **Dedicated Automated Unit Tests**: Comprehensive tests validating edge cases, calculations, and data persistence.
- **Pre-populated Demo Seed Data**: Ready for immediate demonstration without initial blank screens.
- **19-Section Comprehensive `README.md`**: Covering architecture, installation, credentials, and troubleshooting.
- **Academic Project Documentation (`ACADEMIC_REPORT.md`)**: Complete report draft with Mermaid diagrams (Architecture, ER Diagram, DFD, Sequence diagrams).
- **Presentation Slides (`PRESENTATION_SLIDES.md`)**: Structured 8–12 slide deck outline for college presentations.
- **Viva Voce Preparation (`VIVA_QUESTIONS.md`)**: 15+ in-depth viva questions and technical answers.
- **Demonstration Guide (`DEMO_GUIDE.md`)**: Step-by-step evaluator testing checklist.
